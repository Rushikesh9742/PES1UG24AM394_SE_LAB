# SE Lab 4 — VibeCoding: Lunar Lander

## Deliverables
1. `before_changes.mp4` — original gameplay video recorded before code changes.
2. `after_changes.mp4` — final gameplay video after the changes.
3. `game.py` — updated game source code implementing all four tasks.
4. `chat_history_summary.pdf` — a concise record of the work and task decisions.
5. `chat_history_link.txt` — link to the ChatGPT conversation.

## Tasks addressed
- **Task 1:** Safe touchdown checks the landing pad, horizontal speed (`MAX_SPEED_X`), vertical speed (`MAX_SPEED_Y`), and angle (`MAX_ANGLE`).
- **Task 2:** `ship_color(fuel_ratio)` shifts the hull toward red as fuel decreases.
- **Task 3:** `on_landing(score)` prints feedback after a successful landing.
- **Task 4:** `bonus_life_threshold()` returns `1500`.
